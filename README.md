A program that writes one line of horror — a single sentence, under 200 characters — to `/output/entry.txt`, for the [One Line, One Chill](https://make.fun/c/u-azazex-one-line-one-chill-6d4d5488) competition on make.fun.

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt`.
